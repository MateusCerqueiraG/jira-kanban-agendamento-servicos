🟢 Projeto Jira - Sistema de Agendamento e Gestão de Serviços (Metodologias Ágeis)

🤔 Sobre o projeto

Este projeto é um mapeamento e estruturação de um sistema de agendamento e gerenciamento de serviços focado em uma oficina desenvolvido com foco em estudo e prática de metodologias ágeis utilizando o Jira Software.
O objetivo é simular um cenário real de desenvolvimento de software, aplicando conceitos de quebra de escopo, gerenciamento de fluxo contínuo e priorização de demandas (Histórias de Usuário e Bugs).

👨‍💻 Tecnologias e Conceitos utilizados

Jira Software (Cloud)
Metodologia Ágil (Kanban)
Engenharia de Requisitos (User Stories)
Gestão e Rastreabilidade de Bugs
Priorização por Raias (Swimlanes / Expedite)

📊 Objetivo do projeto

Praticar a organização de projetos com metodologias ágeis no Jira
Simular o fluxo de trabalho de equipes de tecnologia (Dev, QA e Product Owner)
Trabalhar com a quebra de grandes escopos em Épicos, Tarefas (Tasks) e Falhas (Bugs)
Desenvolver habilidades práticas de escrita de User Stories focadas na experiência do usuário
