# 🟢 Projeto Jira - Sistema de Agendamento e Gestão de Serviços (Metodologias Ágeis)

## 🤔 Sobre o projeto

Este projeto consiste na modelagem e organização de um sistema de agendamento e gestão de serviços voltado para uma oficina mecânica, desenvolvido com foco em estudo e prática de metodologias ágeis utilizando o Jira Software.

O objetivo é simular um cenário real de desenvolvimento de software, aplicando conceitos como quebra de escopo, organização de backlog, priorização de demandas e fluxo contínuo de trabalho com base em Histórias de Usuário e Bugs.

---

## 👨‍💻 Tecnologias e conceitos utilizados

- Jira Software (Cloud)
- Metodologias Ágeis (Kanban)
- Engenharia de Requisitos (User Stories)
- Gestão e rastreabilidade de Bugs
- Priorização de demandas (Swimlanes / Expedited / High Priority)
- Organização de backlog e fluxo de trabalho

---

## 📊 Objetivo do projeto

- Praticar a organização de projetos utilizando metodologias ágeis no Jira
- Simular o fluxo de trabalho de equipes reais de tecnologia (Dev, QA e Product Owner)
- Realizar a quebra de escopo em Épicos, Histórias de Usuário, Tasks e Bugs
- Desenvolver habilidades na escrita de User Stories com foco na experiência do usuário
- Entender na prática o ciclo completo de uma demanda dentro de um fluxo Kanban

---

## 🔄 O que foi praticado no projeto

- Criação e organização de Épicos
- Escrita de User Stories com critérios de aceitação
- Priorização de backlog
- Simulação de fluxo Kanban (To Do → In Progress → Review → Done)
- Identificação e registro de possíveis bugs
- Estruturação de um cenário próximo a um ambiente real de desenvolvimento
